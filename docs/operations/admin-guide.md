# 激活码管理后台使用指南

> 这是你（卖家）日常卖货、售后、看数据的地方。全程只认激活码，没有用户注册。

## 一、怎么打开

浏览器访问（把 IP 换成你的服务器，或备案后用域名）：

```
http://服务器IP:7900/admin?key=你的ADMIN_KEY
```

`ADMIN_KEY` 是你部署时生成的管理密钥（`/etc/biliparser-license.env` 里的 `ADMIN_KEY`）。

> ⚠️ 建议日常走 SSH 隧道访问，别让密钥明文过公网：
> ```bash
> ssh -L 7900:127.0.0.1:7900 ubuntu@服务器IP
> # 然后浏览器开 http://127.0.0.1:7900/admin?key=你的ADMIN_KEY
> ```

## 二、发码（卖货）

页面上方有个「生成」表单：

| 输入框 | 填什么 |
|---|---|
| 生成几个 | 一次批量生成的数量（1~100） |
| 备注 | 给买家记个名（如「微信昵称-张三」），方便以后对账 |
| 有效期 | 天数，**留空 = 永久**；填 365 就是一年后过期 |

点「生成激活码」，下面绿框会列出新码，复制发给买家即可。

**批量卖（接发卡平台）**：点「导出未激活码」→ 得到一个 txt（一行一码）→ 导入发卡平台（独角数卡/佰阅等），买家付款自动收码。

## 三、看懂列表

每一行是一个激活码，各列含义：

| 列 | 含义 |
|---|---|
| 状态 | 未激活 / **已使用·网页** / **已激活·桌面** / 已禁用 |
| 绑定设备 | 桌面版激活时绑定的设备指纹（网页版为空，一码通用不占设备位） |
| 首次使用 | 买家第一次用这个码的时间 |
| 最近活跃 | 最近一次 AI 调用日期 |
| 今日用量/配额 | 今天用了多少次 AI / 每天上限（默认 100） |
| 解绑次数 | 换机解绑的次数（异常高说明可能被反复转让，要留意） |

## 四、行内操作按钮

| 按钮 | 用途 | 什么时候用 |
|---|---|---|
| **禁用** | 立即让这个码失效（所有端都踢下线） | 退款、封号、买家跑单 |
| **启用** | 恢复被禁用的码 | 误操作、买家补款 |
| **解绑** | 清空绑定的设备，允许换新设备激活 | 买家换电脑、卖二手 |
| **配额** | 改这个码每天 AI 次数上限 | 给大客户调高、给白嫖党调低 |

## 五、日常场景速查

| 场景 | 操作 |
|---|---|
| 卖一个码 | 生成 → 复制 → 发买家 |
| 批量上架 | 导出未激活码 → 导入发卡平台 |
| 退款/封号 | 找到那个码 → 点「禁用」（立即生效） |
| 买家换电脑 | 找到那个码 → 点「解绑」→ 买家重新激活 |
| 看谁在用 | 看「首次使用」「最近活跃」两列 |
| 查 AI 花了多少 | 「今日用量/配额」列 |
| 调每日额度 | 配额输入框填新值 → 点「配额」 |

## 六、常见问题

- **状态一直是「未激活」**：码还没人用，正常。
- **「已使用·网页」但买家说没买**：可能是码泄露了，考虑禁用重发。
- **「解绑次数」涨得快**：有人把码转卖，及时禁用。
- **想改已发出的码的备注**：重新生成一个即可（已发的码备注暂不支持编辑）。

## 七、备份（重要）

`licenses.db` 一个文件就是全部家当，丢了所有码都作废。建议：

```bash
# crontab 每日备份
0 3 * * * cp /opt/biliparser-license/licenses.db /backup/licenses-$(date +\%Y\%m\%d).db
```
