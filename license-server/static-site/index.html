安装步骤

macOS

下载 .dmg 并双击打开

把 BiliParser 拖入 Applications 文件夹

首次打开若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 底部点「仍要打开」（应用未经 Apple 公证，需确认一次；正在办理开发者公证）

Windows

下载 .exe 安装程序并双击运行

若弹出蓝色 SmartScreen 提示，点「更多信息」→「仍要运行」

按引导完成安装，桌面自动生成快捷方式

💡 首次使用需要：① 在设置里填入 B 站 SESSDATA（拉字幕必需，软件内有获取教程）② 输入激活码（联系卖家购买）。AI 调用由服务器代理，无需自己配模型 Key。

常见问题

需要联网吗？

需要。激活与 AI 总结经授权服务器；断网 72 小时内仍可浏览已生成内容，AI 功能恢复联网后自动可用。

会封 B 站号吗？

软件只调用网页版公开接口读取字幕，请求量与正常看视频相当；SESSDATA 仅保存在你本机。

支持哪些视频？

有字幕的视频效果最好（绝大多数视频都有 B 站 AI 字幕）；刚发布 1~2 天的新视频字幕库可能未就绪，可先用「元数据+热评」模式。

换电脑怎么办？

一码一机；新电脑重新激活前，联系卖家在后台解绑旧设备即可。
