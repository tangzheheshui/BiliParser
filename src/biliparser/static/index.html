如何获取 SESSDATA？
获取 SESSDATA：
1. 电脑浏览器登录 bilibili.com，打开任意一个视频
2. 按 F12 打开开发者工具
3. 点顶部「应用程序」标签
4. 左侧「存储」下展开「Cookie」，点 bilibili.com
5. 右侧列表找到「SESSDATA」这一行，双击它的「值」单元格全选
6. 按 Ctrl+C 复制，回到这里 Ctrl+V 粘贴
改动 SESSDATA 后建议重新拉取字幕。
